# Week 2 Assignment

This repository contains a C# console application for managing employee data using a simple class-based structure and LINQ queries.

## Project Overview

The program:
- creates employee objects
- loads employee data asynchronously
- displays all employees in a table format
- finds the employee with the highest salary
- filters employees with salary above 50,000
- filters employees by department

## Files
- `Employee.cs` - Employee model
- `EmployeeData.cs` - Employee data source
- `EmployeeStructure.cs` - Helper methods for employee operations
- `Program.cs` - Main program entry point

## Run the project

Open the solution in Visual Studio and run the project, or use the .NET CLI:

```bash
dotnet run
```

## Notes

This assignment demonstrates beginner-level C# programming and LINQ usage in a console application.
